# H. DEV — Portfólio

Portfólio pessoal construído com React, Vite, CSS e Ionicons. O visual mistura uma base minimalista escura com detalhes neon discretos.

## Executar localmente

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
npm run preview
```

## Seções

- Início e apresentação
- Sobre e áreas de interesse
- Sites e aplicações
- Área reservada para jogos futuros
- Contato

Atualize os links e descrições no array `projects` em `src/App.jsx`. As imagens de prévia ficam em `public/previews/`. Troque também o endereço `contato@exemplo.com` pelo seu e-mail antes de publicar.
